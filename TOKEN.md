# Как обновить токен увлажнителя

После сброса Wi-Fi и повторного добавления в Mi Home токен и IP могут измениться. Обновляйте оба поля.

## 1. Подготовить QR-extractor

Команды ниже выполняются **в Git Bash из корня проекта**. Нужны Git и Python 3.12 с Windows Launcher (`py`). Временная папка `.tools` исключена из Git; после очистки проекта её нужно создать заново.

```bash
mkdir -p .tools
git clone https://github.com/PiotrMachowski/Xiaomi-cloud-tokens-extractor.git .tools/token-extractor
git -C .tools/token-extractor switch --detach c4db715dace9806e905153c2977608873e8ab7c9
py -3.12 -m venv .tools/token-venv
./.tools/token-venv/Scripts/python.exe -m pip install -r .tools/token-extractor/requirements.txt
```

Если `py` не найден, установите Python 3.12 с python.org или замените `py -3.12` на путь к установленному Python.

Ограничьте локальный HTTP-сервер QR-кода адресом своего компьютера:

```bash
./.tools/token-venv/Scripts/python.exe -c "from pathlib import Path; p=Path('.tools/token-extractor/token_extractor.py'); p.write_text(p.read_text(encoding='utf-8').replace('0.0.0.0', '127.0.0.1'), encoding='utf-8')"
```

Это сторонний инструмент с открытым исходным кодом. Используется закреплённая версия исходников, а не готовый EXE. При повторном использовании уже установленного extractor команды установки пропустите.

## 2. Получить актуальные данные

```bash
./.tools/token-venv/Scripts/python.exe .tools/token-extractor/token_extractor.py
```

1. Выберите **`q`** — вход по QR-коду.
2. Отсканируйте QR через Mi Home и подтвердите вход. Если картинка не открылась, используйте локальную страницу `http://127.0.0.1:31415` либо ссылку, которую покажет инструмент.
3. Выберите регион, в котором прибор сейчас добавлен в Mi Home. Пустой регион позволяет искать по всем серверам.
4. Найдите именно **`zhimi.humidifier.ca7`** и скопируйте его **IP** и **TOKEN** локально.

При поиске по всем регионам могут появиться старые записи одного прибора с разными реквизитами. Ориентируйтесь на текущую привязку в Mi Home и текущий IP в списке клиентов роутера.

Extractor выводит секреты всех найденных устройств. Не отправляйте полный вывод, токены, BLE-ключи или QR-сессию в чат и не добавляйте их в Git.

## 3. Обновить конфигурацию

Откройте `device.local.json` в редакторе и замените **только значения** `ip` и `token`. Формат:

```json
{
  "ip": "АКТУАЛЬНЫЙ_IP",
  "token": "32_ШЕСТНАДЦАТЕРИЧНЫХ_СИМВОЛА"
}
```

Не копируйте токен весов или другого устройства. Для увлажнителя токен должен состоять ровно из 32 символов `0–9`, `a–f`.

## 4. Применить и проверить

```bash
docker compose up -d --no-deps --force-recreate api
```

Подождите 10–15 секунд и откройте **http://localhost:8080**. Нажмите «Обновить»: прибор должен быть «На связи», а время измерения — текущим. Nginx переподключается к новому API автоматически.

Если связи нет, проверьте текущий IP, регион привязки, токен и доступ сервера к UDP 54321. Таймаут сам по себе не отличает неправильный токен от сетевой блокировки. Пароль Wi-Fi и аккаунта в `device.local.json` не нужны.
