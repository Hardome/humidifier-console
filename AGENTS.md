# Правила проекта

Читайте [карту документации](docs/README.md) по теме задачи.
Фронт: [web/AGENTS.md](web/AGENTS.md). Python: [правила](docs/rules/python.md).
Используйте Node.js 24+, pnpm 11+, Python 3.12 и uv.
Проверки: `corepack pnpm check`, фронт: `corepack pnpm --dir web check`.
Генерируемые модели и API-клиент вручную не меняйте; меняйте контракт и
запускайте `corepack pnpm codegen`. Сохраняйте пользовательские изменения.
Комментарии пишите по-русски. Не коммитьте напрямую в main; перед коммитом
создайте ветку задачи, сохранив staged и unstaged изменения.

Не читайте и не выводите локальные секреты без необходимости задачи. Не
отправляйте команды реальному прибору и уведомления в рамках автотестов.
Проверяйте изменения поведения регрессионными тестами; не ослабляйте проверки
ради прохождения CI. В отчёте отделяйте выполненные проверки от предположений
и непроверенных сценариев. Процесс: [разработка с AI](docs/guides/ai-development.md).
