# Проверка фронта

Используйте изолированный тестовый API из Playwright; не отправляйте тестовые команды реальному
прибору. На мобильной и настольной ширине проверьте обе темы.

1. Обзор показывает показания и состояния связи; команда получает подтверждение.
2. История показывает разрывы, фильтры и события; даты проверяются до запроса.
3. Автоматизации позволяют создать, изменить и удалить выключенное правило.
4. Настройки сохраняются, фоновый опрос сохраняет несохранённый ввод.
5. Журнал событий сохраняет фильтры в URL, пагинация не дублирует запросы.
6. При потере связи и ошибке БД отображаются соответствующие сообщения.
7. Тема сохраняется после обновления; системная реагирует на настройки ОС.
8. При запрете localStorage тема меняется в текущей вкладке.
9. Клавиатурный фокус видим, горизонтального переполнения страницы нет.
