# Документация humidifier-console

Структура и принципы разработки адаптированы из Hardome/stageby, локальная
ревизия `840307f`. Доступность удалённого main при переносе не подтверждена.
Оформление приложения и предметные правила принадлежат humidifier-console.

| Каталог | Назначение |
| --- | --- |
| `rules/` | Требования и правила разработки |
| `guides/` | Инструкции по выполнению задач |
| `templates/` | Шаблоны планов и решений |
| `decisions/` | Принятые решения и последствия |
| `reports/` | Результаты проверок выпусков |
| `plans/` | Планы текущих циклов до полной приёмки |
| `tmp/plans/`, `tmp/tasks/` | Локальные материалы вне Git |

приёмки. Не дублируйте правила: оставляйте ссылки на основной документ.
Обновляйте карту и ссылки при переносе файлов.
