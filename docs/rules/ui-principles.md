# Принципы интерфейса

Сохраняйте зелёную палитру, компоновку и размеры humidifier-console.
Из stageby используются только принципы, без переноса дизайн-системы.

Цвета задаются семантическими токенами в `web/src/app/styles/theme.css`.
Раскладку, адаптивность и оформление блоков задавайте Tailwind-классами
в компонентах. Каталог `app/styles` содержит только базовые стили и токены тем;
`app/styles.css` связывает импорты. Компоненты используют роли фона, текста, границ, ошибок и состояний;
не добавляйте отдельные dark-классы цветов. Цвета графика берутся из тех же
токенов и обновляются при переключении темы. Декоративный прибор имеет
собственную палитру, независимую от поверхностей интерфейса.

Доступны системная, светлая и тёмная темы. По умолчанию используется
системная; выбор сохраняется локально. При запрете localStorage выбор
действует в текущей вкладке. Скрипт до загрузки React применяет тему без
вспышки светлого фона. Системная тема реагирует на изменение настроек ОС.

Используйте существующие Base UI/shadcn примитивы, доступные подписи,
семантические состояния и видимый клавиатурный фокус. Выбор обозначается
не только цветом. Учитывайте prefers-reduced-motion.

Статический каркас остаётся видимым при загрузке. Скелетоны повторяют форму
содержимого; составные скелетоны имеют отдельные файлы. DataRegion отвечает
за aria-busy, первоначальную загрузку, индикатор фонового обновления и
блокирование устаревшей области при смене фильтров. Данные остаются в Query.
Ошибки и повтор запроса размещаются вне блокируемой области.

Проверяйте обе темы, hover, выбор, фокус, ошибки и отключённые действия
на мобильном и широком экране. Карточки, таблицы и графики должны сохранять
контраст, а фоновые обновления — введённые значения и фокус.

## Скругления

Источник радиусов — токены `--radius-*` в `web/src/app/styles/theme.css`.
Поля ввода, селекты, кнопки всех размеров, переключатели и ссылки навигации
используют `rounded-control` (`--radius-control: 10px`).
Размер и состояние элемента не меняют радиус. В слитной группе внутренние
углы прямые, внешние используют тот же токен (включая вертикальные группы).
Не задавайте отдельные значения в пикселях и не переопределяйте радиус
элемента управления на странице.

Поверхности используют шкалу: `rounded-lg` (14px) для блоков метрик,
`rounded-xl` (20px) для карточек и главного блока прибора.
Бейджи сохраняют форму капсулы, скелетоны повторяют форму содержимого.
Декоративная иллюстрация прибора не относится к компонентам управления.
